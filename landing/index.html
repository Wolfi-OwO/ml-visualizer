Die Visualisierungen

Vier Algorithmen. Ein Prinzip: Parameter anfassen.

Jede Seite ist ein eigenständiges Experiment mit echten, live berechneten Ergebnissen – keine vorgerenderten Bilder.

Gradient Descent

Wie ein Algorithmus Schritt für Schritt das Minimum einer Funktion findet. Lernrate verändern und sehen, wann er konvergiert – oder überschießt.

/gradient-descent

Perceptron

Das einfachste künstliche Neuron trainiert live eine Trenngerade für die AND-Verknüpfung – Epoche für Epoche mitverfolgen.

/perceptron

KNN Visualizer

Punkte platzieren und direkt sehen, wie K-Nearest-Neighbors sie anhand ihrer nächsten Nachbarn klassifiziert. k frei einstellbar.

/knn-visualize

Neural Network

Ein kleines neuronales Netz lernt die AND-Funktion von Grund auf. Gewichte, Trainingsverlauf und Wahrheitstabelle live mitverfolgen.

/neuronal-net

Über das Projekt

Gebaut, um ML wirklich zu verstehen – nicht nur darüber zu lesen.

Der ML Visualizer ist ein Lernprojekt von Kofler Phillip (HTL Villach, Ausbildungszweig Informatik). Er entstand aus der Überzeugung, dass man Algorithmen besser versteht, wenn man ihre Parameter selbst verändern kann, statt nur statische Diagramme auf einer Folie zu betrachten.

Der Code ist quelloffen und wird laufend um neue Visualisierungen erweitert.
